## 4. Keunggulan & Peningkatan dari Desain Lama

1. **Struktur Hero Tidak Monoton**:
   * Desain lama hanya teks rata tengah. Desain baru menggunakan split bento card dengan quick highlight pencapaian teknis.
2. **Kategori Stack Terorganisir**:
   * Badge skill dikelompokkan berdasarkan pilar tanggung jawab (*Frontend, Backend/Data, AI/DevOps*), bukan sekadar tumpukan tag acak.
3. **Card Proyek Berstandar Mockup Browser**:
   * Setiap gambar proyek memiliki border double-bezel dan rasio proporsional, serta tombol akses langsung ke demo dan GitHub repo.
4. **Mobile Experience Teroptimasi**:
   * Floating dock di desktop bertransisi menjadi bottom bar ringkas di mobile agar tidak memotong area baca.
